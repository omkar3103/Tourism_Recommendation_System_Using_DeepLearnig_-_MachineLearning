SETUP the Environment
Open the Travel project folder

s1: Create the Virtual Environment:
	python -m venv tourism_venv

s2: Activate the tourism_env
	\tourism_env\Scrits\activate

s3: After activate tourism_env - run the below cmd to install all requirements 
	pip install -r requirements.txt

s4: After installing the requirements Run the below cmd to run the projecr
	python app.py
